# Update the app on GitHub and Render

1. Extract this ZIP.
2. In the GitHub repository connected to Render, choose **Add file → Upload files**.
3. Upload the contents of the `campus-calendar-render` folder to the repository's top level, replacing files with matching names.
4. Commit the changes. Render will redeploy from GitHub.

After deployment, open the site and choose **Calendar → Import timetable** to upload a CSV or `.ics` file. Imports add classes and keep the existing calendar entries.
